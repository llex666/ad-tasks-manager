# Changelog

## [1.0.0] - 2026-11-23

Первый публичный выпуск / Initial public release.

- Интерактивное меню в стиле sconfig; программа сначала показывает меню, сканирование запускается по выбору.
- Выбор типа компьютеров (все / пользовательские / серверы и ВМ) и OU для сканирования; результаты накапливаются.
- Индикатор выполнения, прерывание по Esc.
- Раздельные таблицы для компьютеров пользователей и серверов/ВМ, сводка, список недоступных компьютеров.
- Действия по имени на всех или выбранных компьютерах, выбор строк в Out-GridView, лог, экспорт в CSV.
- Параметры `-Domain` (по умолчанию домен текущего пользователя) и `-StaleDays`.
