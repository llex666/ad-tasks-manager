# AD Scheduled Tasks Manager

Интерактивная консольная утилита на PowerShell (меню в стиле `sconfig`) для **инвентаризации и удаления заданий планировщика Windows** на всех компьютерах домена Active Directory — пользовательских ПК, серверов и виртуальных машин.

> [English version](README.en.md)

## Возможности

- Сбор **всех заданий планировщика** со всех компьютеров домена или только из выбранной OU.
- Раздельные таблицы: **компьютеры пользователей** и **серверы / ВМ** (тип определяется по `OperatingSystem` в AD).
- Выбор, что сканировать: все компьютеры, только пользовательские или только серверы. Можно сканировать **отдельные OU** (вместе с вложенными); результаты сканирований накапливаются.
- **Индикатор выполнения** опроса, прерывание клавишей `Esc` (уже собранные данные сохраняются).
- Сводка «задание → на скольких компьютерах оно есть» (отдельно клиенты и серверы).
- **Удаление задания по имени** со всех или с выбранных компьютеров (все / только клиенты / только серверы / выбор вручную).
- Удаление отдельных строк (компьютер + задание), выбранных в окне `Out-GridView`.
- Системные задания `\Microsoft\*` по умолчанию скрыты, а при попытке их удалить показывается предупреждение.
- Подтверждение удаления вводом `YES`, подробный лог, экспорт в CSV.
- Список недоступных компьютеров с причиной.

## Требования

- Windows PowerShell 5.1 (разрабатывалось и использовалось в нём; PowerShell 7 не проверялось).
- Модуль **ActiveDirectory** (RSAT) на машине, с которой запускается скрипт.
- Учётная запись с правами администратора на опрашиваемых компьютерах (например, доменный администратор).
- Доступ к целевым компьютерам по **WinRM (TCP 5985)** или **RPC/DCOM (TCP 135)**: сначала используется WinRM, при неудаче — DCOM.
- Целевые ОС с модулем `ScheduledTasks` (Windows 8 / Server 2012 и новее).
- Для выбора строк вручную нужен `Out-GridView` (на Server Core его нет).

## Быстрый старт

```powershell
git clone https://github.com/llex666/ad-tasks-manager.git
cd ad-tasks-manager

# запуск (домен берётся из $env:USERDNSDOMAIN)
powershell -ExecutionPolicy Bypass -File .\Manage-DomainScheduledTasks.ps1

# или с параметрами
.\Manage-DomainScheduledTasks.ps1 -Domain corp.example.com -StaleDays 60
```

Программа **сначала показывает меню** — ничего не сканируется, пока вы не выберете пункт `1`.

## Параметры

| Параметр      | По умолчанию               | Описание                                                     |
|---------------|----------------------------|--------------------------------------------------------------|
| `-Domain`     | `$env:USERDNSDOMAIN`       | DNS-имя домена AD                                            |
| `-StaleDays`  | `90`                       | Пропускать компьютеры, не заходившие в домен более N дней    |

## Меню

```
  Сканирование
   1) Запустить сканирование с текущими параметрами
   2) Тип компьютеров: [все компьютеры]  (нажмите, чтобы переключить)
   3) Область (OU): [весь домен corp.example.com]
   C) Очистить результаты

  Просмотр
   4) Задания: компьютеры пользователей
   5) Задания: серверы и виртуальные машины
   6) Сводка по заданиям (имя → на скольких ПК)
   U) Недоступные компьютеры

  Изменение
   7) Удалить задание по имени (все / выборочно)
   8) Удалить выбранные строки (Out-GridView)

  Прочее
   M) Системные задания \Microsoft\*: скрыты
   E) Экспорт в CSV
   0) Выход
```

Клавиши работают и в русской раскладке (например, `U` = `Г`, `M` = `Ь`, `E` = `У`, `C` = `С`).

## Как это работает

1. Из AD (`Get-ADComputer`) берутся включённые Windows-компьютеры, заходившие в домен не позднее `-StaleDays` дней назад; применяются фильтры типа и OU.
2. Параллельно проверяются порты 5985 и 135.
3. Создаются CIM-сессии (WinRM, при неудаче DCOM).
4. Задания читаются через `Get-ScheduledTask -CimSession` пачками по 8 сессий (с индикатором выполнения).
5. Удаление выполняется через `Unregister-ScheduledTask` в соответствующей CIM-сессии.

## Безопасность и ограничения

- **Удаление необратимо.** Сначала проверьте работу на пилотной OU. Перед удалением скрипт показывает список и требует ввести `YES`.
- Скрипт читает задания вместе с учётными записями запуска и командными строками: лог (`DomainTaskManager.log`) и CSV-выгрузки могут содержать чувствительные данные. Не публикуйте их (они уже в `.gitignore`).
- Лог и CSV пишутся рядом со скриптом (если скрипт запущен не из файла — во временную папку).
- Компьютеры, которые выключены или недоступны по портам, попадают в раздел «Недоступные».
- Авторы не несут ответственности за последствия использования (см. лицензию).
